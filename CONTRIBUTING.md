# Участие в разработке

## Локальный запуск

```bash
npm install
npm run dev
```

Проверка типов и сборка:

```bash
npm run typecheck
npm run build
```

## Что можно улучшить

- Пресеты колонок для конкретных банков (Сбер, Т-Банк, Альфа, ВТБ).
- Новые правила категоризации и категории.
- Тесты парсера: кодировки, разделители, даты, суммы, шапка не в первой строке.
- Импорт PDF-выписок.
- Доступность и мобильные сценарии.

## Правила

- Не добавляйте сервер, аналитику и внешние трекеры без явного обсуждения.
- Не отправляйте содержимое выписок в сторонние API по умолчанию.
- Деньги храните в копейках (`number`), не во `float`.
- Для новых функций — небольшой PR с описанием сценария.

## Баги

Пришлите:

- банк и формат файла (CSV/XLSX);
- первые строки шапки без персональных данных;
- что ожидали и что получилось.
