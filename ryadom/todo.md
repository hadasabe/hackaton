# Состояние «Рядом»

## Точка продолжения

Публичный сайт: https://art-progulka-saratov.vercel.app/ .
Содержимое перенесено в отдельную папку общего репозитория по запросу пользователя.
Приложение «Стена» пока не объединяется с гидом. Зависимости и конфигурация
основного приложения не менялись. Временные файлы, runtime синтеза, сборки и
учётные данные не включать в Git.

## Выполнено

- Мобильный гид:57 мест,17 арт-объектов,52 основных фото,54 кадра галерей.
- Бесплатный одобренный голос Денис:56 готовых MP3; одна история pending.
- GPS100м, демо4,5км/ч, галереи, избранное и упорядоченный план прогулки.
- До переноса проверены20 тестов, интерфейс390/1280px и публичное воспроизведение.
- После переноса:15 Node и5 Python тестов прошли; пересборка каталога и release
  успешны; все56 аудиофайлов проверены по SHA256. Исходники интерфейса побайтно
  совпадают с одобренной версией сайта. Временные файлы и сборки исключены.
- Ветка добавления: `feature/ryadom-standalone`; изменения только в `ryadom/`.
