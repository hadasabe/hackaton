# Решения

- 2026-11-20, Codex по запросу пользователя: сохранить самостоятельный buildless
  HTML/CSS/JS гид рядом со «Стеной» в `ryadom/`. Это перенос в общий репозиторий,
  без объединения интерфейсов, серверов и данных. Пересмотреть при отдельном
  согласовании интеграции; альтернатива немедленного переписывания на React отложена.
- Сохранены Leaflet1.9.4/OSM и Python-сервер без внешних пакетов. Данные и MP3
  включены, чтобы сайт запускался из клона без генерации и ключей.
- Денис/Piper выбран и одобрен пользователем; локальный бесплатный предсинтез.
  Runtime и модель в Git не входят. Пересмотреть при изменении текста или голоса.
- Координаты пользователя только в памяти вкладки. localStorage — настройки и
  идентификаторы подборок. Облачная синхронизация не реализуется без нового запроса.
- Координаты исходных16 объектов перенесены из временной папки в
  `data/coordinates.json`, чтобы пересборка каталога не зависела от файлов вне Git.
