# Проверенные технические особенности

- GPS телефона требует HTTPS. HTTP-адрес локальной сети не заменяет HTTPS;
  localhost на самом компьютере подходит для локальной проверки.
- Загрузка голосов устройства асинхронна; запасной синтез ожидает voiceschanged.
  Основной голос — готовые MP3 Дениса, он не зависит от установленных голосов.
- Piper/eSpeak в проверенном Windows-наборе не распознавал абсолютный путь с
  кириллицей. Проверено решение: относительный ASCII espeak_data_dir из каталога
  переносного runtime, без патча библиотеки. См. generate_neural_audio.py.
- NC-фотографии с noCrop показывать целиком; не помещать их в круглую маску
  фотометки. Файлы с noResize не перекодировать.
- Service worker не кэширует тайлы OSM; отсутствие сети может скрыть подложку,
  даже если тексты и ранее загруженные изображения доступны.
