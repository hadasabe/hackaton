# Рядом — арт-прогулка по Саратову

Самостоятельный мобильный веб-аудиогид: карта, достопримечательности в радиусе
100 метров, GPS и спокойный нейроголос Денис. Размещён рядом с приложением
«Стена» (`../graffiti/`). Приложения пока не объединены: у них отдельные запуск,
интерфейсы и данные. Код «Стены» при добавлении этого каталога не изменялся.

Публичная версия: [art-progulka-saratov.vercel.app](https://art-progulka-saratov.vercel.app/).
Добавление в GitHub само по себе не меняет эту публикацию.

## Запуск

Нужен Python 3.10 или новее. Дополнительные пакеты для запуска не требуются.
Из корня общего репозитория:

```powershell
cd ryadom
python server.py
```

Откроется `http://127.0.0.1:8765`. Альтернатива в Windows — двойное нажатие
`Запустить MVP.cmd`. Остановить сервер: Ctrl+C. Если порт занят:
`python server.py --port 8766`. Демо-прогулка работает без разрешения GPS.

На настоящем телефоне GPS требует HTTPS; обычный адрес локальной сети по HTTP
для этого не подходит. Координаты пользователя обрабатываются только в памяти
вкладки. В localStorage сохраняются настройки, избранное и порядок остановок.
При очистке данных браузера подборки удалятся.

## Что работает

- 57 мест, включая 17 арт-объектов: муралы, граффити, мозаики и скульптуры.
- 52 основных фото, 54 кадра галерей; у пяти мест проверенного снимка пока нет.
- 56 готовых MP3 Дениса, около 66 минут. У одной истории сведения уточняются,
  автоматический рассказ отключён. Нейросинтез бесплатный и выполнен локально;
  для прослушивания не нужны API-ключи или подключение к TTS-сервису.
- Карта Leaflet/OpenStreetMap, фотометки, стрелка направления движения,
  карточки и истории с источниками, поиск, галереи, избранное, план прогулки.
- Демо со скоростью 4,5 км/ч. Радиус и расстояния считаются по прямой;
  план прогулки не заменяет пешеходную навигацию.
- PWA и кэш ранее загруженных материалов. Картографической подложке нужен
  интернет; тайлы OSM не предзагружаются.

Для GPS нажмите «Начать прогулку». Держите приложение открытым: работа при
заблокированном экране не гарантируется. Полевой GPS на настоящем телефоне
и текущая сохранность граффити ещё требуют проверки.

## Проверки и сборка

Из папки `ryadom/`:

```powershell
node --test tests/geo.test.cjs
python -m unittest discover -s tests -v
node --check app.js
node --check experience.js
python tools/build_catalog.py
python tools/build_release.py
```

Node.js нужен только для проверок JavaScript. Каталог пересобирается из
`data/coordinates.json`, `editorial.json`, `additional-places.json`,
`art-places.json`, `photos.json` и `galleries.json`.
Сборка создаёт игнорируемые `release/` и `ryadom-mobile.zip`; публикация автоматически
не выполняется. Готовый `data/places.js` хранится в Git, чтобы сайт запускался сразу.

В `audio/` лежат готовые записи. `data/audio-manifest.js` содержит параметры,
хеши текстов и MP3. После изменения истории нужно обновить соответствующую
запись и манифест; старое аудио не считать актуальным автоматически.
`tools/generate_neural_audio.py` требует отдельно подготовленный совместимый
переносной Piper runtime в `preview/runtime/piper-1.8.0/`, модель Denis и Windows
Python 3.12. Большой runtime и модель в Git не включены; скрипт их не устанавливает.
`generate_audio.py` — неиспользуемый платный вариант SpeechKit: запуск сети
в нём защищён отдельным флагом, платные запросы в этом проекте не выполнялись.

## Файлы и права

`app.js`/`geo.js` — карта, GPS и звук; `experience.js` — подборки и галереи;
`server.py` — локальный статический сервер; `tests/` — проверки.
Источники и условия для каждого снимка находятся в `data/photos.json`,
`data/galleries.json` и доступны в интерфейсе. См. [THIRD_PARTY.md](THIRD_PARTY.md).

Память проекта: [todo.md](todo.md), [decisions.md](decisions.md),
[BUGS.md](BUGS.md), [GOTCHAS.md](GOTCHAS.md), [STYLE.md](STYLE.md).
Работать в отдельных ветках; включать изменения в общую `main` после ревью команды.
